# Archived v1 evidence (single-service app, next-day forecast)

These are the original, unmodified logs and measurements for HeatGuard v1.0/v1.1
(one FastAPI container serving both API and dashboard, 1-day forecast).
They were superseded by v2.0 (7-day forecast, separate frontend and backend), whose
evidence is in `experiments/results/`. Kept for transparency; nothing here was edited.
